Adicione este objeto como um novo campo de primeiro nível do arquivo "network":

"qkd": {
  "enabled": true,
  "qtndKm": 25.0,
  "quantumCoreId": 6
}

IMPORTANTE:
- qtndKm: distância máxima de um trecho QKD antes de um nó confiável lógico.
- quantumCoreId: deve corresponder a um id já existente no array "cores".
- Para a primeira validação use o núcleo externo que você pretende reservar à QKD.
- Não adicione ainda percentual de requisições QKD aqui. O 95%/5% será uma
  característica de tráfego e será implementado em etapa posterior.
- Se "qkd" estiver ausente ou "enabled" for false, o cenário continua sendo
  tratado como clássico para esta etapa.
